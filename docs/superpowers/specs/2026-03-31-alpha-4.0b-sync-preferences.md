# Alpha 4.0b — Sync Preferences & Agent Profiles

## Overview

Sync user preferences (dark mode, language, terminal settings) and agent profiles to Supabase when logged in. Without login, everything works locally as before. Last-write-wins conflict resolution.

## What Syncs

| Data | Local Source | Supabase Table |
|------|-------------|----------------|
| Dark mode, language | app-store + DOM | `user_preferences` |
| Terminal: theme, font, fontSize, ligatures | `app-store.ts` | `user_preferences` |
| Agent profiles | `AgentProfiles/profiles.json` | `agent_profiles` |

## Sync Flow

```
App opens → auth initialized → user logged in?
  ├─ No → use local data as-is
  └─ Yes → fetch preferences from Supabase
           ├─ Exists? → apply to app (overwrite local)
           └─ Not found? → upload local to Supabase

User changes preference → save local + upsert to Supabase (debounced 1s)
```

- **No login** = zero impact, works exactly as today
- **With login** = automatic sync, no manual buttons
- **Conflict** = last write wins (upsert with `updated_at`)

## Supabase Schema

```sql
CREATE TABLE user_preferences (
  user_id UUID PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE,
  dark_mode BOOLEAN DEFAULT true,
  language TEXT DEFAULT 'en',
  terminal_theme TEXT DEFAULT 'Default',
  terminal_font TEXT DEFAULT '''Cascadia Code'', monospace',
  terminal_font_size INT DEFAULT 13,
  terminal_ligatures BOOLEAN DEFAULT false,
  updated_at TIMESTAMPTZ DEFAULT now()
);

CREATE TABLE agent_profiles (
  id TEXT NOT NULL,
  user_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
  name TEXT NOT NULL,
  provider TEXT NOT NULL,
  model TEXT DEFAULT '',
  api_key TEXT DEFAULT '',
  system_prompt TEXT DEFAULT '',
  autonomous BOOLEAN DEFAULT false,
  updated_at TIMESTAMPTZ DEFAULT now(),
  PRIMARY KEY (user_id, id)
);

ALTER TABLE user_preferences ENABLE ROW LEVEL SECURITY;
CREATE POLICY "users own preferences" ON user_preferences FOR ALL USING (auth.uid() = user_id);

ALTER TABLE agent_profiles ENABLE ROW LEVEL SECURITY;
CREATE POLICY "users own profiles" ON agent_profiles FOR ALL USING (auth.uid() = user_id);
```

## Sync Module

`src/lib/sync.ts` — all sync logic in one file:

```typescript
// Preferences
fetchPreferences(userId: string): Promise<UserPreferences | null>
pushPreferences(userId: string, prefs: UserPreferences): Promise<void>

// Agent profiles
fetchAgentProfiles(userId: string): Promise<AgentProfile[]>
pushAgentProfiles(userId: string, profiles: AgentProfile[]): Promise<void>
pushAgentProfile(userId: string, profile: AgentProfile): Promise<void>
deleteAgentProfile(userId: string, profileId: string): Promise<void>
```

All functions are no-ops when `isSupabaseConfigured` is false. All functions catch errors silently (sync failure should never break the app).

## Store Changes

### app-store.ts
- Add `darkMode: boolean` and `language: string` to store state (currently managed outside Zustand)
- On any setting change: save locally + call `pushPreferences()` debounced

### agents-store.ts
- On profile create/update/delete: existing local save + call sync function debounced

### auth-store.ts
- After successful login: trigger full sync (fetch remote → apply to stores)
- On logout: no action (local data stays)
